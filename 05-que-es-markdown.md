# Qué es Markdown

**No necesitas aprenderlo.** Tu agente escribe así, y esta página está aquí solo por si te pica la
curiosidad o te encuentras un archivo y quieres entender lo que ves.

## En una frase

Los documentos de tu proyecto son **archivos de texto** que terminan en `.md`. Markdown es una forma
de escribir títulos, negritas o listas **con unos pocos signos**, sin un programa como Word.

## Lo que vas a ver

| Lo que está escrito | Lo que significa |
|---|---|
| `# Título` | Un título grande. Con `##`, uno más pequeño |
| `**importante**` | **importante**, en negrita |
| `*matiz*` | *matiz*, en cursiva |
| `- algo` | Un punto de una lista |
| `1. algo` | Un punto de una lista numerada |
| `[texto](dirección)` | Un enlace |
| `\| a \| b \|` | Una fila de una tabla |
| `> algo` | Un aviso o una cita, apartado del resto |

Por eso la mayoría de los documentos **se leen bien aunque los abras tal cual**: los signos están
pensados para molestar poco.

## Para verlo con formato

En VS Code, con el documento abierto, pulsa **Ctrl+Shift+V**: se abre una vista previa con los
títulos, las negritas y las tablas como en una página.

Si en un documento ves un bloque que empieza por `mermaid`, es un **dibujo** —un esquema o un
diagrama de flujo—. En la vista previa se ve dibujado: ArmonIA instala lo necesario.

## ¿Y si quiero escribir yo?

Puedes. Escribe normal: si no usas ningún signo, sale texto normal, y no se rompe nada. Si quieres
una negrita o una lista, **pídesela a tu agente**, que para eso está.
